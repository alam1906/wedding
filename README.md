# Wedez

[https://wedez.id](https://wedez.id)

## Tentang

Wedez adalah aplikasi undangan pernikahan digital untuk membuat undangan yang personal,
memilih tema, mengelola informasi acara dan daftar tamu, serta menerima konfirmasi kehadiran (RSVP).
Undangan dapat dibagikan melalui link dengan subdomain khusus.

## Tech Stack

- **Frontend:** Svelte 5, SvelteKit, TypeScript, dan Tailwind CSS.
- **Animasi:** GSAP.
- **Validasi:** Valibot.
- **Backend & database:** PocketBase dan SQLite.
- **Runtime & build:** Bun dan Vite.
- **Pembayaran:** Duitku.
- **Deployment:** Docker Compose, Caddy, Traefik, Dokploy, GitHub Actions, dan GitHub Container Registry (GHCR).
